Làm theo 6 bước

Không cần làm nhiều việc cùng lúc. Xong bước nào mới sang bước tiếp theo.

Máy chỉ cần có 2 thứ chính:

  1. Node.js LTS — để chạy lệnh npm.
  2. VS Code — để mở project và mở Terminal dễ hơn.
Sau khi cài Node.js, đóng VS Code rồi mở lại để máy nhận lệnh mới.

Kiểm tra Node.js đã hoạt động chưa:

Terminal
node -v

Nếu hiện dạng v20.x, v22.x... là được.

Tiến độ được lưu trên trình duyệt này.

Cách dễ cho người mới: trên GitHub chọn Code → Download ZIP, sau đó giải nén.

Nhớ giải nén ZIP trước. Không chạy project trực tiếp bên trong file ZIP.

Nếu đã biết dùng Git, có thể dùng lệnh:

Terminal
git clone https://github.com/taimesut/pleiku-03.git

Trong VS Code:

  1. Chọn File → Open Folder.
  2. Chọn thư mục project vừa tải về.
  3. Nhìn bên trái và kiểm tra có file package.json.
  4. Chọn Terminal → New Terminal.
Mẹo kiểm tra: nếu thấy package.json ở danh sách file bên trái thì gần như bạn đang đứng đúng chỗ.

Copy lệnh sau, dán vào Terminal rồi nhấn Enter:

Cài dependencies
npm install

Lệnh này có thể chạy một lúc. Khi xong, project sẽ có thư mục node_modules.

Có warning màu vàng chưa chắc là lỗi. Chỉ cần chú ý nếu Terminal dừng với chữ error và không chạy tiếp được.
Chạy môi trường dev
npm run dev

Terminal sẽ hiện một địa chỉ dạng:

Ví dụ
Local: http://localhost:5173/

Giữ Terminal đó đang chạy và mở địa chỉ trên bằng trình duyệt.

Muốn dừng: quay lại Terminal và nhấn Ctrl + C.

Đảm bảo lệnh dev đã dừng, sau đó chạy:

Build project
npm run build
Nếu Terminal chạy xong và không có error, hãy nhìn trong project. Bạn sẽ thấy thư mục dist. Đó là kết quả build.

Riêng project này: lệnh build còn chạy script hậu xử lý để chuẩn bị file HTML dùng cho Google Apps Script.

Tùy chọn: đưa bản mới lên Google Apps Script

Nếu máy đã được cài và đăng nhập clasp:

Đi vào thư mục GAS
cd gas
Đẩy code lên Apps Script
clasp push

Sau đó vào Apps Script và tạo New version cho Web App nếu muốn cập nhật bản đang dùng.

Nếu gặp lỗi, kiểm tra 4 thứ này trước

Đây là các lỗi người mới gặp nhiều nhất.

“npm is not recognized”

Node.js chưa được cài đúng hoặc VS Code chưa mở lại sau khi cài Node.js.

“package.json not found”

Terminal đang đứng sai thư mục. Mở lại đúng folder có file package.json.

Trang web không mở

Kiểm tra Terminal chạy npm run dev còn hoạt động và mở đúng URL localhost được in ra.

Build báo error

Đừng đọc cả màn hình. Kéo xuống gần cuối và tìm dòng error đầu tiên để biết file nào đang lỗi.
